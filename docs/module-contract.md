# 平台 BFF 架构与安全边界

## 设计

该模块嵌入 233 的 `anbo_wx` Flask 应用，复用统一登录、JWT、组织、菜单和审计。它是浏览器与内网服务之间唯一的业务代理，不将采集库、AIOps 或 ClickHouse 账号下发给浏览器。

## 数据与依赖

| 目标 | 用途 | 访问方向 |
| --- | --- | --- |
| 233 MySQL `anbo_wx` | 用户、组织、权限、审计 | 本机 |
| 236 `18086` / `3339` | 采集状态与采集业务数据 | 233 → 236 |
| 20 `18080` | AIOps 代理，使用服务间签名 | 233 → 20 |
| 212 `8123` | ONU/OLT/Radius 历史分析 | 233 → 212 |

## 端口与安全

用户入口为 **233:5772**。Gunicorn/BFF `7001` 只绑定 `127.0.0.1`；233 MySQL `6603` 仅允许必要管理网段。233→20 的共享签名密钥只能保存于受控运行配置，不写入 Git。
